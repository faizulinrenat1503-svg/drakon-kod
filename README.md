# Дракон.Код — сайт

Многостраничный статический сайт на [Eleventy](https://www.11ty.dev/) (генератор статических сайтов).
На выходе — обычные HTML, CSS и JS, без фреймворков в браузере. Форма заявки отправляется
на PHP-обработчик — так же, как на сайте dragon-trade.

## Что нужно

- Node.js 18+ (проверено на 24).
- Один раз после скачивания проекта: `npm install`.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Локальный просмотр на http://localhost:8080 с автообновлением. Форма в этом режиме **не отправляется** на сервер — заявка выводится в консоль браузера. |
| `npm run build` | Собирает сайт в `_site/` и обработчик формы в `_backend/`. |
| `npm run stubs` | Собирает список всех заглушек `[ЗАПОЛНИТЬ]` / `[ПРОВЕРИТЬ]` в `ZAGLUSHKI.md`. |

## Как выложить на хостинг

1. Заполните домен в `src/_data/site.js` (константа `DOMAIN`) и запустите `npm run build`.
2. **Сайт:** загрузите **содержимое** папки `_site/` в корень сайта на хостинге
   (там, где должен лежать `index.html`).
3. **Обработчик формы:** загрузите содержимое папки `_backend/` на адрес из
   `site.form.endpoint` (по умолчанию поддомен `form.<домен>`, как у dragon-trade).
   Затем на сервере, рядом с `submit.php`:
   - скопируйте `config.example.php` в `config.php` и впишите пароли SMTP, почту для заявок и,
     если есть, данные MySQL. **`config.php` не хранится в git** — только на сервере;
   - нужен PHP 8+ с расширениями `pdo_mysql` (если используется база) и `openssl`.
4. Если обработчик будет по другому адресу (например, в папке самого сайта) — поменяйте
   `form.endpoint` в `src/_data/site.js` и пересоберите.

### Как работает обработчик (`backend/submit.php`)

- Принимает заявки только с адресов из `form.allowedOrigins` (`src/_data/site.js`).
  При сборке этот список записывается в `_backend/origins.php`.
- Если в `config.php` настроена база — сохраняет заявку в таблицу `drakon_kod_leads`
  (создаётся сама, с заявками dragon-trade не пересекается).
- Отправляет письмо через SMTP: имя, телефон, группа, комментарий, страница.
- Сбой базы не мешает письму. Ошибку сайт показывает, только если не удалось ни то, ни другое.
- Ошибки и факт отправки пишутся в `errors-log.php` — его нельзя открыть через браузер.
- Скрытое поле `website` — ловушка для спам-ботов.

## Где что править

| Что | Файл |
|---|---|
| Домен, адрес обработчика формы, CORS, контакты, реквизиты, показатели, меню, флаг отзывов | `src/_data/site.js` |
| Товарные группы (названия, плашки, даты, тексты) | `src/_data/groups.json` |
| Услуги (4 шага) | `src/_data/services.json` |
| Вопросы и ответы | `src/_data/faq.json` |
| Коэффициенты калькулятора | `src/_data/calculator.json` |
| Отзывы (сейчас скрыты) | `src/_data/reviews.json` + `features.reviews` в `site.js` |
| Цвета, шрифты, радиусы | `src/assets/css/tokens.css` |
| Логотип | `src/_includes/components/logo.njk` |
| Картинка для соцсетей | `src/assets/img/og-image.png` (1200×630) |

Заглушки `[ЗАПОЛНИТЬ]` и `[ПРОВЕРИТЬ]` подсвечиваются на страницах янтарным, чтобы их было
видно до запуска. Когда вписываете настоящий текст, просто удаляйте метку.

## Структура

```
src/
  _data/          данные и тексты (см. таблицу выше)
  _includes/
    layouts/      base.njk — общий каркас страницы (head, SEO, шапка, подвал, модальное окно)
    components/   header, footer, logo, macros (форма, карточки, FAQ, хлебные крошки), calculator, reviews
  assets/         css, js, img
  index.njk       главная
  sitemap.njk, robots.njk
backend/          submit.php, config.example.php
scripts/          build-backend.js, stubs.js
```
